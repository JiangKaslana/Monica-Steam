# 设置与使用建议

Monica Steam 的设置页按功能重新分组，避免把安全、界面、Steam 体验和应用级选项全部混在同一长列表里。

## 设置分区

当前设置大致可以理解为四类：

### 安全与数据

包括：

- 主密码；
- 生物识别；
- 本地账号数据；
- `maFile` / ZIP；
- WebDAV 备份与恢复；
- 日志相关能力。

涉及账号迁移或远程备份前，建议先阅读 [备份与本地安全](../guide/backup-security)。

### 界面与交互

包括 Monica 系列配色和 Material 3 / Material 3 Expressive 相关界面能力，例如：

- Monica 全套配色；
- Monica Plus 配色；
- 固定底栏；
- 悬浮 Dock；
- 液态玻璃 Dock；
- 界面缩放；
- 减少动效等。

不同设备对透明、模糊和动画的性能表现差异较大。如果出现明显掉帧，可以先关闭更重的视觉效果。

### Steam 体验

包括：

- 商店相关提示；
- Steam 链接打开方式；
- 通知；
- 网络优化；
- Steam 忽略列表同步等。

### 应用

包括：

- 语言；
- 日志；
- 其他应用级行为与扩展设置。

## 网络优化怎么配

普通用户推荐从最简单配置开始：

```text
动态 DNS / DoH：开
解析来源：选择 1～2 个稳定来源
静态 Hosts：先关
```

如果某些 Steam 域名在动态解析下仍然长期异常，再使用静态 Hosts 扫描。

### 不建议一上来全部打开

解析来源越多，不代表最终 Steam 线路一定越好。

“全部测速”适合比较可用性；动态解析则只需要启用自己真正信任、稳定的几个来源。

### 自定义 DoH

自定义 DoH 保存后会进入统一解析来源列表，并同时可供：

- 动态 DNS / DoH；
- 静态 Hosts 扫描；
- 单独测速；
- 全部测速。

如果希望自建一个简单的 Google DoH Relay，可参考 [Cloudflare Worker 反代 Google DoH](../network/cloudflare-google-doh)。

## IPv6

如果当前网络具有稳定原生 IPv6，可以尝试开启 IPv6 优先。

如果出现部分域名 IPv6 路由质量差、连接时间明显变长，则可关闭优先策略，让应用优先使用更稳定的地址顺序。

## 商店忽略列表同步

本地忽略状态会优先即时更新界面。

如果开启 Steam 官方同步，Monica Steam 会尝试把本地待同步操作更新到 Steam；如果暂时同步失败，本地状态不会立即回滚。

如果只希望在 Monica Steam 内隐藏某些内容，可以关闭官方同步。

## 内置浏览器

Steam 网页会使用独立 WebView 模块。

为了降低风险，未知网页权限、非 Steam 站内跳转、混合内容和第三方 Cookie 默认更保守。

文件下载通常交给外部浏览器处理。

## 日志

排查问题时可以查看和分享日志，但公开提交前先检查是否含有敏感信息。

尤其不要公开：

- Steam Guard 密钥；
- 密码；
- Cookie；
- 完整 `maFile`；
- WebDAV 密码；
- 私有 DoH TOKEN。

## 设置搜索

设置首页搜索可以匹配子页面中的具体选项。进入子分类后再返回时，首页和分类页会分别保留滚动位置，适合快速定位复杂设置。

## 推荐的“稳妥起点”

如果你第一次使用，建议先保持：

```text
默认主题
默认 Dock
动态 DNS / DoH：只启用系统 DNS + 一个可信 DoH
静态 Hosts：关闭
WebDAV：暂不启用
Steam 官方忽略同步：按需
```

确认账号、令牌、商城、聊天都正常以后，再逐项开启高级设置。
