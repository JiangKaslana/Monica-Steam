## 支持会用在哪里

项目 README 当前说明，赞助优先用于：

- Steam 协议适配；
- Steam 风控风险降低；
- Android 体验优化；
- 稳定性改进；
- 聊天与通知维护；
- 备份能力维护；
- Monica 系列持续开发。

## 其他支持方式

除了赞助，也可以：

- 提交可复现的 Issue；
- 补充经过脱敏的日志；
- 测试新版本；
- 帮忙完善文档；
- 提交 Pull Request；
- 在确认问题后补充设备、Android 版本和复现步骤。

## 提交问题时不要公开

- Steam Guard 密钥；
- 密码；
- Cookie；
- 完整 `maFile`；
- WebDAV 密码；
- 私有 DoH TOKEN；
- 其他可以恢复账号控制权的敏感资料。
