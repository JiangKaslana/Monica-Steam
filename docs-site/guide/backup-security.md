# 备份与本地安全

Monica Steam 处理的不只是普通设置数据，还可能包含 Steam Guard、账号会话和 `maFile` 等敏感资料。备份和本地保护因此属于核心功能，而不是可有可无的附加项。

## 本地保护

当前应用提供：

- 主密码；
- Android 生物识别（BiometricPrompt）；
- 加密本地存储；
- 可选 MDBX 存储；
- Android 应用沙箱隔离。

Monica Steam 使用独立应用 ID：

```text
takagi.ru.monica.steamapp
```

因此可以和 Monica Android / Monica Pass 并排安装，数据不会自动互通。

## Steam 专用备份

备份能力主要服务于 Steam 账号数据，包括：

- `maFile`；
- Steam 账号 ZIP 导入 / 导出；
- WebDAV 备份与恢复；
- 本地账号数据库相关资料。

它不是 Monica Pass 密码库备份功能。

## 推荐备份策略

至少保留两份彼此独立的备份：

```text
手机内 Monica Steam
        │
        ├── 本地离线备份
        │
        └── 另一位置的加密备份 / WebDAV
```

如果只有一份备份，并且它和手机放在同一个存储介质上，那么手机损坏、误删或文件系统故障时仍然可能一起丢失。

## 导入前

在导入新账号或覆盖已有资料前：

1. 导出现有 `maFile` / ZIP；
2. 检查备份文件确实存在；
3. 不要立即删除旧设备或旧验证器；
4. 完成导入后先确认令牌、账号和会话正常；
5. 再考虑清理旧环境。

## WebDAV

WebDAV 适合做跨设备或远程备份，但它也引入了远程服务凭据和网络依赖。

建议：

- 使用自己信任的 WebDAV 服务；
- 单独保存 WebDAV 凭据；
- 不要在公开日志、截图或 Issue 中泄露地址和密码；
- 定期验证备份确实可以恢复，而不仅是“上传成功”。

## ZIP 导入 / 导出

ZIP 更适合手动迁移或离线存档。

导出后不要把文件长期放在公共下载目录、聊天软件自动同步目录或无加密网盘中。

## 主密码与生物识别

主密码提供应用层保护；生物识别用于减少日常解锁摩擦。

它们不能替代：

- Android 锁屏；
- 系统账户保护；
- 设备加密；
- 备份文件本身的妥善保管。

## 日志

Monica Steam 提供日志查看、清除与分享能力。

在提交 Issue 或分享日志前，建议检查其中是否包含：

- SteamID；
- URL 参数；
- 自定义 DoH 地址；
- WebDAV 地址；
- 账号名称；
- 会话异常信息。

不要把令牌密钥、Cookie、完整 `maFile` 或密码直接贴到公开 Issue。

## 丢失设备怎么办

如果设备丢失：

1. 优先处理 Steam 官方账号安全；
2. 撤销不再信任的设备会话；
3. 检查 Steam Guard 与恢复方式；
4. 修改可能泄露的远程备份凭据；
5. 使用已保存的独立备份恢复到新设备。
